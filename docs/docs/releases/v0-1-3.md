---
title: v0.1.3
description: Keyboard, focus and selection parity with React Aria across collection, picker, colour and overlay components.
---

**Released:** 2026-10-04

```bash
npm i @hareui/vue@0.1.3
```

## Behaviour Changes

- **ColorSlider:** a `name`d slider now submits the channel value (e.g. `200` for hue, `0.5` for alpha) instead of the colour as hex, as React Aria does. The alpha thumb's `aria-valuenow` uses the same 0–1 scale.
- **Popover:** now modal. Outside content is hidden from assistive tech while it is open, and focus returns to the trigger on close.

## Bug Fixes

### Collections

- **ListBox:** range selection, select-all, Escape to clear, Page Up/Down and typeahead now match React Aria.
- **Table:** a single roving tab stop, plus range selection.
- **TagGroup:** focus is restored after removing a tag; range selection added.
- **Tabs:** focus stays on the selected tab; tab stops match React Aria.
- **ToggleButtonGroup:** Home and End are ignored, as in React Aria.

### Pickers and menus

- **Select:** opens on press start and selects on release, focuses options on hover, keeps the selection on Escape and restores focus to the trigger.
- **ComboBox:** clearing the input commits an empty value; options stay rendered through the exit animation.
- **Autocomplete:** opens on press start and selects on release.
- **Dropdown:** focus wraps, Page Up/Down added, and Escape closes only the open submenu.

### Dates

- **Calendar:** Page Up/Down keys, the selected date is kept, and outside-month days are ignored.
- **RangeCalendar:** range selection follows React Aria, with live preview and drag.
- **DatePicker / DateRangePicker:** open, close and focus behaviour match React Aria.
- **DateInputGroup:** Page Up/Down keys, 12-hour wrap and segment ARIA state.

### Colour

- **ColorArea:** channels are read from the model converted to the area's colour space.
- **ColorField:** formatting, stepping and form submission match React Aria; the submitted hex stays lowercase.
- **ColorPicker:** focus returns to the trigger after an outside click.
- **ColorSwatchPicker:** Page Up/Down jump to the first/last swatch, Left/Right arrows work in the stack layout, and the picker no longer steals focus.

### Inputs

- **Checkbox:** clicking the glyph toggles once, Enter submits the form, focus is kept when read-only, and root clicks made in the same millisecond as mount are forwarded.
- **NumberField:** an emptied input commits, paging moves by one step, and the `update:modelValue` emit type is restored.
- **TextField:** no longer emits `update:modelValue` on mount.
- **SearchField:** Escape and Enter are ignored while read-only or disabled.
- **InputGroup:** focus stays on interactive suffix content.
- **InputOTP:** the active slot's character is selected, as in `input-otp`.
- **Slider:** thumbs are labelled, range thumbs can no longer cross, and page size matches React Aria.

### Overlays

- **Modal / AlertDialog / Drawer:** Tab skips scrollable bodies; content stays mounted through the exit animation; the page's `aria-hidden` is released after close.
- **Drawer:** enter and exit animations run on the compositor.
- **Toast:** F6 moves focus to the toast region; focus is kept on keyboard dismiss.
