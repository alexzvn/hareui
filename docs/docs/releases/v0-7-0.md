**Released:** 2026-11-09

```bash
npm i @hareui/vue@0.7.0
```

## New

### Component aliases

- The `hareui()` Vite plugin takes `aliases`, a map from a tag name to a HareUI component: `aliases: { Btn: 'Button' }` makes `<Btn>` auto-import `Button`. The prefix doesn't apply to alias names, and an alias pointing at a component that doesn't exist fails when the plugin starts. See [Frameworks](/docs/getting-started/frameworks#aliases).
- `defineAlias(Component, { props, ui, class })` makes a preset: a component that renders `Component` with your default props and classes. What you pass on the instance wins, `ui` merges per slot, and slots, `v-model` and template refs pass through. See [Composition](/docs/getting-started/composition#presets).
- `createHareUI({ components })` registers components globally by name, for presets or for apps that don't use the Vite plugin.

### Unstyled components

- `createHareUI({ unstyled: true })` renders every component without HareUI's classes, and `unstyled: ['button', 'card']` only the listed ones. The `ui` and `class` props, data attributes and behavior stay. Setting `unstyled` on the injected `hareUIConfigKey` config restyles mounted components, inside `<App>` too. See [Theming](/docs/getting-started/theming#unstyled-components).
- A few classes moved from themes into component markup so they survive `unstyled`: the `sr-only` labels of ChatAttachment, ChatLoader, ChatMessageActions, DropZone, NumberStepper and RichTable; the `touch-none` of drag handles and the `select-none` of the Sheet, DashboardResizeHandle and RichTable ones; `relative` on ColorArea and ColorSlider; the hit area of the Table and RichTable column resizers; RichTable's scroll container, pinned columns and sticky header and footer; and the positioning of the Slider fill, Rating stars, PressableFeedback ripple, chart tooltip and overlay, Carousel track and Map's canvas, markers, popups and controls. Styled output is unchanged; a `createHareUI({ ui })` override of those slots no longer removes them.
- Tabs toggles its scroll buttons, and Calendar and RangeCalendar their year picker, with `v-show` instead of theme classes.
- Hidden controls stay out of reach under `unstyled`: the empty SearchField and Select clear buttons, and the Calendar and RangeCalendar nav buttons and day grid while the year picker is open, are `inert`.
- RichTable puts its pinned-column classes on pinned cells only, which shortens every other cell's `class`.

### Non-modal popover

- Popover takes `modal` (default `true`). With `:modal="false"`, a `click` popover leaves the page usable: a click outside reaches its target and also closes the popover. Use it for toggletips. See [Popover](/docs/components/popover#non-modal).

## Changes

### Short component classes

- 82 components render short BEM classes (from 81 stylesheets: RangeCalendar shares Calendar's) instead of long Tailwind class lists. For example, a Button's root went from 1745 characters of classes to a few names like `h-button h-button--primary`, and the Autocomplete page's class text shrank from about 79,000 to 8,600 characters. Each component's styles live next to it as `<name>.css` and ship in `@hareui/vue/style.css`. The rendered result is unchanged. The converted components:
  - Buttons and groups: Button, ButtonGroup, ToggleButton, ToggleButtonGroup, CloseButton, Toolbar, Header, Link.
  - Form fields: Label, Description, ErrorMessage, FieldError, Fieldset, Input, InputGroup, TextArea, TextField, NumberField, NumberStepper, SearchField, InputOtp, DateInputGroup, DateField, TimeField.
  - Choices: Checkbox, CheckboxGroup, CheckboxButtonGroup, RadioGroup, RadioButtonGroup, Switch, SwitchGroup.
  - Pickers and menus: Select, ComboBox, Autocomplete, ListBox, Dropdown, ContextMenu, DatePicker, DateRangePicker, Calendar, RangeCalendar.
  - Colors and sliders: Slider, ColorSlider, ColorArea, ColorField, ColorPicker, ColorSwatch, ColorSwatchPicker.
  - Collections and navigation: Table, RichTable, Tree, TagGroup, Pagination, Tabs, Breadcrumbs.
  - Overlays: Modal, AlertDialog, Drawer, Sheet, Popover, Tooltip, Toast.
  - Layout and display: Card, Surface, Separator, Accordion, Disclosure, DisclosureGroup, Avatar, AvatarGroup, Badge, Chip, Kbd, Spinner, Skeleton, ScrollShadow, Typography.
  - Feedback: Alert, EmptyState, Meter, ProgressBar, ProgressCircle.
- The classes sit in `@layer components`, below Tailwind utilities, so a utility you pass through `class` or `ui` now wins in every state, including hover and selected. Before, the component's state styles could win over it. Focus and invalid rings are the exception: a plain `ring-1` doesn't remove them, while a state utility like `focus-visible:ring-4` still replaces them. Each component page lists its classes under "CSS classes".
- Under `unstyled`, ScrollShadow no longer fades its edges. The fade now comes from ScrollShadow's own classes instead of a global stylesheet, so it goes away with the rest of the styling.

## Bug Fixes

- ListView keeps keyboard focus when an arrow key moves it to a row that is scrolled out of view. Before, focus could drop to the page when the scroll took longer than a few frames.
- A disabled CellSlider thumb shows the default cursor. Before, it still showed the pointer cursor.
- Select, ComboBox and Autocomplete keep room for the selected item's checkmark. Before, the popover's item padding removed it, so the checkmark covered short labels like "25".
- Modals, menus and other overlays work inside a shadow root, such as a browser extension panel. Before, the page outside them was made inert along with the shadow host, so their own items ignored clicks and keys. Live regions inside the shadow root, such as toasts, now stay usable as well.
- Accordion items show HeroUI's hover background. Before, the rule was written in a form Tailwind ignored, so hovering did nothing.
- A ColorField input without a suffix keeps its full end padding. Before, it lost 4px whenever any ancestor had a `group` class.
- A RichTable scrolled by an outer element (`virtualize.getScrollElement`) keeps its rounded frame. Before, the header's square corners stuck out past the frame, and the frame stopped at the scroller's width instead of following a wider table.
- An open Disclosure or Accordion panel no longer clips its content. Before, focus rings and shadows that reached past the panel's edges were cut off, for example on a full-width TextArea in a body without side padding. The panel now clips only while it opens or closes.
- Floating and dialog surfaces set their own text colour: Tooltip, Popover, Dropdown, ContextMenu, Select, ComboBox, Autocomplete, the ColorPicker, DatePicker and DateRangePicker popovers, NavigationMenu, Toc, EditorToolbar, EditorSuggestionMenu, ChartTooltip, Modal, Drawer and AlertDialog. Before, they took the text colour from where they were mounted, so a portal target without one, such as a shadow root, showed black text on the dark-mode overlay.
