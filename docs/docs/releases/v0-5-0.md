**Released:** 2026-10-31

```bash
npm i @hareui/vue@0.5.0
```

## New

### New components

- [Metric](/docs/components/metric) is a card that shows one key figure with its trend, progress, sparkline and actions.
- [MetricGroup](/docs/components/metric-group) lays `Metric` cards out on one shared surface, divided by thin lines. `stacked` turns the row into a column, always or below a breakpoint.
- [NumberValue](/docs/components/number-value) formats a number for the locale, as currency, a percentage, a unit or in compact notation.
- [TrendChip](/docs/components/trend-chip) shows a metric change, coloured and arrowed by its direction.
- [Widget](/docs/components/widget) is a dashboard panel with a header of title, description and legend above an elevated content area.
- [ItemCard](/docs/components/item-card) is a row with an icon, a title, a description and a trailing action such as a button, a switch or a select.
- [ItemCardGroup](/docs/components/item-card-group) groups `ItemCard`s on one divided surface or in a grid, with an optional heading.
- [ListView](/docs/components/list-view) is a single-column list of rows with keyboard navigation, selection checkboxes, row actions and links.
- [ActionBar](/docs/components/action-bar) is a floating toolbar fixed to the bottom of the screen for contextual actions, such as bulk actions on selected rows.
- [Marquee](/docs/components/marquee) scrolls content in an endless loop, for rows of logos, testimonials or tags.
- [FormField](/docs/components/form-field) puts a label, description, hint, help text and error around any form control, wires them to the control's accessibility attributes and shows `Form` errors. `useFormField()` gives a custom control the same wiring.

### Locales

- `App`'s `locale` prop takes a `Locale` from `defineLocale()` as well as a BCP 47 code. A `Locale` translates the built-in labels (close buttons, pagination, empty states, screen-reader names), sets date and number formatting from its `code`, and sets the reading direction from its `dir` unless `dir` is set. Keys a locale leaves out fall back to English one by one. Label props you pass still win over the locale. See [App](/docs/components/app#locale).
- `@hareui/vue/locale` ships `en` and 62 ready-made catalogs (`ar`, `de`, `fr`, `ja`, `vi`, `zh_cn` and more), adapted from Nuxt UI's locale catalogs. The right-to-left ones (`ar`, `ckb`, `fa_ir`, `he`, `ug_cn`, `ur`) also set `dir="rtl"`.

### Shared types

- `IconValue` (a class string or a component) is the type of every icon prop and item icon.
- `LinkBaseProps` lists the link fields every link-capable component and item takes: `to`, `href`, `target`, `rel`, `download`, `external`, `replace`, `exact`, `active`, `disabled`.
- `CloseButtonProp` and `CloseButtonOptions` type the `closeButton` prop.

### New features on existing components

#### Button

- `to`, `href` and the other link fields render the button as a link: through `RouterLink` when the app has vue-router and `to` is internal, otherwise a plain `<a>`. `[data-active=true]` marks the current route. A disabled link drops its `href` and gets `aria-disabled="true"`.
- `label`, `leadingIcon`, `trailingIcon` and `avatar` fill the button without slots. With an icon or avatar and no label, the button is square like `iconOnly`.
- `loadingAuto` keeps the button `pending` while the promise returned by `@click` runs and, on a `type="submit"` button, while its parent `Form` submits.

#### Link

- Takes the shared link fields. With vue-router installed, `to` goes through `RouterLink` and `[data-active="true"]` marks the current route (`exact` and `active` adjust the match); without a router, `to` renders a plain `<a>`. `rel` defaults to `noopener noreferrer` with `target="_blank"`. Pass another link component, such as `NuxtLink`, to `as`.

#### Dropdown, ContextMenu, Breadcrumbs, Tabs, Accordion, ListBox

- Items take an `icon`, rendered before the label.
- `Dropdown` and `ContextMenu` items take the link fields and `onSelect(event)`, which runs before the `action` event; `event.preventDefault()` keeps the menu open.
- `Breadcrumbs` items take the link fields. The last item and disabled items render without a link.

#### Icon props

- Every icon prop and item icon takes a class string or a component. `CodeBlock` `icon`, `Stepper` and `Timeline` item icons, `Sidebar` `icon`, `Toc` `trailingIcon` and the `EditorToolbar` item icons took only a component before.

#### Modal, Drawer, AlertDialog

- New events: `enter` and `leave` when the open and close animations start, `after:enter` and `after:leave` when they end, and `close:prevent` when Escape or a press outside tries to close one with `dismissible` set to `false`.
- `closeButton` takes an object with an `icon` and a `label` (its accessible name) to customise the close button.

#### Alert and Toast

- `Alert` takes `closeButton`: clicking it hides the alert and sets `v-model:open` to `false`.
- A toast's `closeButton` takes `false` to hide the close button, or an object with an `icon` and a `label`.

#### Popover

- `mode="hover"` opens the popover while its trigger is hovered or focused, after `openDelay` (700ms), and closes it `closeDelay` (300ms) after the pointer or focus leaves. `enable-touch` opens it on a tap. In hover mode the `content` slot gets no `close` callback.
- New `close:prevent` event.

#### Tooltip

- `kbds` renders a `Kbd` per entry after the text, hidden below the `lg` breakpoint.

#### EmptyState

- `icon`, `avatar`, `title`, `description`, `actions`, `size` and `variant` props, and `leading`, `title`, `description` and `actions` slots.

#### Form controls

- `Input`, `TextArea` and `TextField` take `v-model` modifiers: `trim`, `number`, `lazy`, plus `nullable` (an emptied field commits `null`) and `optional` (it commits `undefined`). `NumberField` takes `nullable` and `optional`.
- `Select`, `ComboBox`, `Autocomplete`, `CellSelect` and `InlineSelect` emit `change`, `focus` and `blur`. `ComboBox` and `Autocomplete` also emit `highlight` with the highlighted option.
- `Checkbox`, `Switch` and `DropZone` emit `change`.

## Changes

- `CellSelect` and `InlineSelect` emit `null` instead of `undefined` when the selection is cleared.
- `TextField` clears its text when `v-model` is set to `null`, as it already did for `undefined`.
- `@focus` and `@blur` listeners on `InputOtp` and `NumberField` go to the input, so they fire when the input gains and loses focus.
- In right-to-left layouts the `Tabs` selection indicator sits under the selected tab. Before, it was offset by the width of the list.
- In right-to-left layouts a `Drawer` with `placement="left"` or `"right"` docks on that physical side. Before, it docked on the opposite side while sliding in from the named one.

## Breaking changes

`FormFieldProps` is renamed `FormFieldValidationProps`, and `NavigationMenuIconValue` and `CommandPaletteIcon` are replaced by `IconValue`. `Input`, `TextArea` and `TextField` can emit `null`, and `CellSelect` and `InlineSelect` emit `null` when cleared. `@focus` and `@blur` on `InputOtp` and `NumberField` listen on the input. Menu, tab, accordion and select items render their own `icon` field. See [Migrating from v0.4.0 to v0.5.0](./migrations/v0.4.0-v0.5.0.md) for every change, with before and after code.

## Accessibility

- Built-in labels such as close buttons, pagination buttons and `Kbd` key names are read from the app's locale, so screen readers announce them in the page's language.
- `FormField` links its label, description, hint, help text and error to the control with `aria-describedby` and `aria-invalid`.
