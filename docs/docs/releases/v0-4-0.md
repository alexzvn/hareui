```bash
npm i @hareui/vue@0.4.0
```

## New

### New components

- [ContextMenu](/docs/components/context-menu) opens at the pointer on right click or long press, with sections, item groups, submenus, single or multiple selection, shortcuts and item slots.
- [Stepper](/docs/components/stepper) is a horizontal or vertical step indicator with `v-model`, linear navigation, `next()` / `prev()`, item icons, partial line progress, colors and sizes.
- [Timeline](/docs/components/timeline) lists events in order, with icon or avatar markers, per-item status tones, `v-model` progress, vertical or horizontal orientation, a centred axis with alternate placement, and per-item slots.
- [Rating](/docs/components/rating) shows or collects a score as a row of icons, with `v-model`, half and fractional steps, clearable, hoverable, read-only, custom icons or an `#item` slot, and Form validation.
- [Tree](/docs/components/tree) shows expandable folders and files with indent guides, single, multiple and checkbox-style selection, controlled expansion, per-item slots and virtualization.
- [Splitter](/docs/components/splitter) lays out resizable panels from an `items` prop, with line, drag, pill and handle grips, collapsible panels, keyboard resizing and layout persistence (`auto-save-id`).
- [Sidebar](/docs/components/sidebar) is a standalone collapsible sidebar with `offcanvas`, `icon` or `none` collapse, `sidebar`, `floating` or `inset` variants, a rail, and a slideover, drawer or modal menu on mobile that closes when a link inside it is clicked (`auto-close`).
- [Toc](/docs/components/toc) is a table of contents that follows the heading in view, as a sticky list (collapsible below `lg`, with an optional straight or circuit highlight) or as floating marks that open the links on hover or press.

### Components in entries of their own

These four are imported from their own path, not from `@hareui/vue`, so apps that don't use them don't need their peer dependencies. The `@hareui/vue/vite` plugin and `HareUIResolver` import them from that path, so auto import works for them as well.

- [CommandPalette](/docs/components/command-palette) (`@hareui/vue/command-palette`): grouped commands with fuzzy search, keyboard navigation, `v-model` and `v-model:search-term`, nested lists, shortcuts, match highlighting, virtualization and per-group slots. Needs `fuse.js`.
- [Carousel](/docs/components/carousel) (`@hareui/vue/carousel`): slides with arrows, dots and thumbnails, `in-place`, `modal` and `miniatures` types, vertical and RTL support, and arrow-key navigation. Needs `embla-carousel-vue`; the autoplay, auto-scroll, auto-height, class-names, fade and wheel-gestures plugin props each load their own `embla-carousel-*` package only when set.
- [CodeBlock](/docs/components/code-block) (`@hareui/vue/code-block`): code with a filename or language header, copy button, highlighted lines and line numbers. Highlighting uses `shiki` when it's installed, with light and dark themes.
- [Editor](/docs/components/editor) and `EditorToolbar` (`@hareui/vue/editor`): a rich-text field with HTML, JSON or Markdown `v-model`, fixed, bubble and floating toolbars, dropdown commands and custom handlers. Needs the `@tiptap/*` packages listed on its page.

### Overlays from code

`useOverlay()` opens a `Modal`, `Drawer` or `AlertDialog` from code and resolves with the value it closes with. `App` renders the `OverlayProvider` it needs. See [Overlays](/docs/getting-started/overlays).

## Changes

- `Popover`, `Dropdown`, `Modal`, `Drawer`, `AlertDialog`, `DatePicker` and `DateRangePicker` render on the server again. In v0.3.0 they threw `Element is not defined` during server rendering, for example in Nuxt.
- A `PieChart` centre label and its `#center` slot sit at the centre of the pie that is drawn, including a composed `ChartPie` with its own `cx`, `cy` or radii. Previously they stayed at the middle of the chart.
- `ComboBox` lists your own `aria-describedby` ids first, before its value, description and error ids, as the other fields do.
- A `justify-*` class in a cartesian chart's `ui.legend` now overrides the default `justify-center`, as it already did on pie, radar and radial charts.
- `Modal`, `Drawer` and `AlertDialog` stay over the visible area when iOS Safari scrolls the page to show the on-screen keyboard. Previously the overlay stayed at the top of the page, so a drawer's header went off screen and its bottom stopped short of the keyboard. A top or bottom `Drawer` is now at most 85% of the visible area's height rather than of the page's, so a tall one keeps its header in view while the keyboard is open.

## Breaking changes

Props that shared a prefix are grouped into one object prop, for example `:prev="{ label, disabled }"` on `Pagination` and `:tick="{ count, formatter }"` on chart axes. `useResizable` takes one options object. See [Migrating from v0.3.0 to v0.4.0](./migrations/v0.3.0-v0.4.0.md) for every change, with before and after code.

## Accessibility

- While a field is invalid, its description is removed from the page and from `aria-describedby`, so screen readers announce only the error. This applies to `TextField`, `NumberField`, `NumberStepper`, `ColorField`, `SearchField`, `Select`, `ComboBox`, `NativeSelect` and `CellSelect`, whose themes already hid the description visually. Date and time fields already did this.
