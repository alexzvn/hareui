
## Bug Fixes

- **ComboBox:** with `v-model`, picking an option now fills the input with its text right away. Before, the input kept the previous option's text until it lost focus. Form reset had the same stale text and is fixed too.
- **SSR:** components no longer throw `ReferenceError: Element is not defined` when rendered on the server (Nuxt, VitePress).
