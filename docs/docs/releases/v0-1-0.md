**Released:** 2026-10-03

```bash
npm i @hareui/vue@0.1.0
```

First public release of `@hareui/vue`: a Vue 3 port of HeroUI v3, built on Reka UI and Tailwind CSS v4.

## Highlights

- The HeroUI v3 component set, rebuilt on [Reka UI](https://reka-ui.com) and checked against `@heroui/react` with computed-style and screenshot diffs.
- Nuxt UI-style API: named slots, a `:ui` prop for per-slot classes, and `createHareUI()` for app-wide theme overrides.
- `v-model` on every stateful component, with uncontrolled `default*` props.
- Theming with CSS variables and tailwind-variants themes. See [Theming](/docs/getting-started/theming).

Start with the [Quick Start](/docs/getting-started/quick-start).
