**Released:** 2026-10-24

```bash
npm i @hareui/vue@0.3.0
```

## New

### New components

**Forms:**

- [CellSwitch](/docs/components/cell-switch), [CellSlider](/docs/components/cell-slider), [CellSelect](/docs/components/cell-select) and [CellColorPicker](/docs/components/cell-color-picker) put a label and its control in one row, for settings panels.
- [CheckboxButtonGroup](/docs/components/checkbox-button-group) and [RadioButtonGroup](/docs/components/radio-button-group) show each option as a selectable card, with an optional icon, description and custom indicator.
- [DropZone](/docs/components/drop-zone) accepts files by drag and drop or from the file picker, filters them by type and size, and lists them with upload progress.
- [InlineSelect](/docs/components/inline-select) is a select that reads as part of a sentence.
- [NativeSelect](/docs/components/native-select) styles the browser's `<select>`, with a label, description and validation.
- [NumberStepper](/docs/components/number-stepper) changes a number with minus and plus buttons around the value.

**Charts:** SVG charts in a separate entry, `@hareui/vue/charts`. They need `d3-scale` and `d3-shape`, which are optional peer dependencies:

```bash
npm i d3-scale d3-shape
```

- [AreaChart](/docs/components/area-chart), [LineChart](/docs/components/line-chart), [BarChart](/docs/components/bar-chart) and [ComposedChart](/docs/components/composed-chart) plot series against an x and a y axis. Areas and bars can be stacked, and a composed chart mixes bars, lines and areas.
- [PieChart](/docs/components/pie-chart), [RadarChart](/docs/components/radar-chart) and [RadialChart](/docs/components/radial-chart) cover pies and donuts, radar plots, and progress rings and gauges.
- [ChartTooltip](/docs/components/chart-tooltip) is the panel shown on hover. Use its parts to build your own tooltip content.
- [ChartLegend](/docs/components/chart-legend) lists a chart's series, and can show or hide them.

Set `index`, plus `series` to pick the fields, and a chart draws its parts for you: grid, axes and tooltip on cartesian charts, slices or rings with a tooltip on pie and radial charts. Add `legend` for a legend that hides a series on click:

```vue
<AreaChart :data="data" index="month" :series="['revenue', 'costs']" stacked />
```

To control every part, place `ChartXAxis`, `ChartArea`, `ChartTooltip` and the other parts inside the chart yourself.

Apps that don't import `@hareui/vue/charts` don't need d3 installed.

Charts take their colors from five new theme variables, `--chart-1` to `--chart-5`: shades of `--accent` from darker to lighter, with `--chart-3` equal to the accent. Tailwind classes such as `bg-chart-2` and `text-chart-4` use them too, and overriding `--accent` recolors every chart.

The `@hareui/vue/vite` plugin and `HareUIResolver` import chart components from `@hareui/vue/charts`, so auto import works for them as well.

## Changes

- `Select` has `side` and `align` props to place its popover, and a `leading` slot before the value.
- A `Select` named only by `aria-label` now announces its label together with the selected value.
- Options in `Select` and `ListBox` show the focus ring only while you use the keyboard, as in `ComboBox` and `Autocomplete`. Opening the list with the mouse no longer rings the selected option.
- A disabled `Slider` sets `aria-disabled` on its thumbs.
- `Slider` submits its value under `name` (`volume=65`) instead of `volume[0]`. A range slider repeats the name for each thumb.
- `Slider` keeps its value inside `min` and `max`, and `changeEnd` reports the new value after an arrow key instead of the previous one.
- `Slider` can be dragged on touch screens without scrolling the page.
- When a form submit fails, a `RadioGroup` now moves focus to its first enabled option instead of the group.
- `@hareui/vue` now depends on `@number-flow/vue`, which NumberStepper uses to animate its value.

## Accessibility

Every component is now audited with axe in its idle, open, selected, disabled and invalid states, and every docs demo is audited in a browser. Keyboard and focus behaviour follow React Aria. Visual output is unchanged except where noted.

Behaviour you may notice:

- While a `Modal`, `Drawer`, `AlertDialog`, `Popover` or `Dropdown` is open, the rest of the page is `inert` as well as hidden from screen readers, so nothing behind it can be focused or clicked. Toasts stay reachable.
- The `DatePicker` and `DateRangePicker` popovers are modal: focus stays inside while open, and a read-only picker no longer opens.
- In single-selection mode, the select-all checkbox of a `Table` is disabled and named "Select", as in HeroUI. Previously clicking it selected every row.
- A `Button` rendered as a non-button element (`as="div"`) gets `role="button"`, joins the tab order and responds to Enter and Space. A `Link` without `href` is focusable and activates on Enter.
- `SearchField`, `InputGroup` and `InputOtp` pass input attributes such as `aria-label`, `autocomplete` and `maxlength` to the input instead of the wrapper. Escape that clears a `SearchField` no longer also closes the dialog around it.
- `Label` has an `as` prop; date and time fields use it to render a `span` group label.
- The `#toast` slot of `ToastProvider` receives `titleId` and `descriptionId`; put them on your title and description so the toast is named.

Names, roles and keyboard support:

- `NumberField` stepper buttons are named after the field ("Increase Width") and point at the input with `aria-controls`.
- `TagGroup` remove buttons are named after their tag ("Remove tag News").
- `Tabs` with a vertical list also move with Left and Right arrows.
- `NavigationMenu`: hover cards open with the arrow key or Enter and close with Escape, vertical items with children expand and collapse with arrows, and collapsed icon-only links are named.
- `Calendar` and `RangeCalendar` grids are named after the visible month, and the year picker is a listbox.
- `ColorSlider` and `ColorArea` thumbs are named after the field label, and `ColorSlider` announces the formatted value ("120°").
- `DashboardSidebarToggle` and `DashboardSidebarCollapse` point at the sidebar with `aria-controls`.
- Removing a file in `DropZone` moves focus to the next file instead of losing it.
- `Select` and `Autocomplete` popovers are named after the field, and section headers in `ListBox` and `Dropdown` no longer register as page landmarks.

## Performance

Faster rendering across the library, with no change to markup, props or events:

- Components share one compiled theme per app instead of building one per instance, which makes mounting and variant changes cheaper everywhere.
- Fields no longer re-render their label, description and error when an unrelated prop changes.
- `ListBox`, `Select`, `ComboBox` and `Autocomplete` re-render only the options that change, so arrow keys, toggling an option and typing in a `ComboBox` stay fast with long lists. Typeahead in a long `ListBox` no longer slows down with the square of the item count.
- Removing a tag from a `TagGroup` no longer re-renders the tags before it.
- `Dropdown` items render their label and description as plain elements, so large menus open faster.
- A closed `Modal`, `Drawer` or `AlertDialog` no longer measures the viewport when it mounts, and all of them share one pair of resize listeners.
- `Tooltip` listens on the document only while it waits to close, instead of keeping five listeners per tooltip.
- Resizing a `DashboardSidebar` or `DashboardPanel` no longer restyles everything inside it on each frame, and neither does scrolling near the edge of a `ScrollShadow`. Pushing a toast onto a long stack restyles less of it.
- `Calendar` and `RangeCalendar` render the year picker's cells in idle time after mounting instead of during it, so a `DatePicker` opens faster and the year picker's first fade-in is not delayed. Hovering a range re-renders only the days whose state changes.
- `RichTable` resolves column pinning once per render instead of once per cell, and skips measuring rows that didn't change.
- Charts measure line length once per draw animation instead of on every frame, cache axis label widths, and stop re-measuring the tooltip on every pointer move.
