npm i @hareui/vue@0.1.1

## Improvements

### Typed items in collection components

`ListBox`, `Select`, `ComboBox`, `Autocomplete`, `TagGroup`, `Tabs`, `Accordion`, `RadioGroup`, `CheckboxGroup` and `Breadcrumbs` are now generic over their item type. Extra fields on your items are typed in slots, so `(item as any)` casts are no longer needed.

```vue
<script setup lang="ts">
const users = [{ value: 'a', label: 'Admin', email: 'a@x.dev' }]
</script>

<template>
  <ComboBox :items="users" label="Owner">
    <template #item="{ item }">{{ item.email }}</template>
  </ComboBox>
</template>
```

Each component page now has a short typing note.

## Bug Fixes

- **Checkbox, Radio, Switch:** clicking anywhere in the item row (empty space, description) now toggles the control, as in HeroUI. Nested interactive content is left alone. ([#7](https://github.com/alexzvn/hareui/pull/7))

## Documentation

- Overview thumbnails for AlertDialog, Drawer, Modal, Popover, Toast and Tooltip now show the overlay open. ([#6](https://github.com/alexzvn/hareui/pull/6))
- Docs demos are typechecked (`bun run typecheck:docs`). ([#8](https://github.com/alexzvn/hareui/pull/8))
